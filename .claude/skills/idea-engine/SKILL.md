# Idea Engine

## Inputs to read first
- `creator/brand-profile.md`: pillars, audience, variable zone, never-us list
- `creator/content-log.md`: recent formats and pillars (to avoid repeats) and top performers (to build on)
- `creator/libraries.md` § Formats

If the profile is empty, run a 3-question mini-interview (niche, audience, platform) and suggest
running `creator-dna` later.

## Generate
Use **at least 4 of these idea sources** for each batch and label each idea with its source:
1. **Pillar × Format matrix:** cross an under-used pillar with an under-used format.
2. **Audience pain / desire:** a specific problem the viewer has this week.
3. **Personal-life mining:** something that actually happened to the creator recently. Ask about it.
4. **Trend adaptation:** take a trend's *mechanic* (structure, transition, sound idea), not
   its literal content, and make it fit the niche. Never copy a trend unchanged.
5. **Comment mining:** questions or arguments from the creator's comments (ask them to paste some).
6. **Contrarian take:** a common belief in the niche the creator disagrees with.
7. **Series seed:** an idea that can run as Part 1/2/3 or Day 1–30.
8. **Collab / guest:** a friend, family member, local shop or other creator.
9. **Remix a winner:** a top post from the log, re-done in a *different* format.
10. **Seasonal / cultural:** festivals, exams, monsoon, weddings, cricket, launches, and so on.

## Score each idea (1–5)
- **Hook potential:** can the first 2 seconds stop a scroll?
- **Shareability:** would someone send this to a friend?
- **Saveability:** is it useful enough to come back to?
- **Effort:** reverse-scored, so 5 means easy.
- **Freshness:** how different it is from the last 7 posts in the log.

## Output
A table: `# | Idea title | Pillar | Format ID | Source | Hook (one line) | Scores | Total`.
Then:
- **Recommended week:** pick 5 that satisfy the repeat rules in `creator/content-log.md` (no
  repeated format back-to-back, balanced pillars, at least 1 low-effort and 1 ambitious idea).
- **One wildcard:** an idea outside the creator's comfort zone, labelled as an experiment.

## Rules
- Default batch is 10 ideas. Make titles concrete ("I lived on ₹500 in Mumbai for a day"), not
  vague ("budget video").
- Never suggest more than 2 ideas in the same format per batch.
