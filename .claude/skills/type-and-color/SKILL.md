# Type & Color

**Principle:** 70% fixed brand, 30% fresh. The anchor font and core colours stay. The accent font, caption
style, grade and text animation rotate.

## Inputs
If the user edits in Instagram Edits, choose font styles by EF code from `creator/edits-app-playbook.md` and use Canva for exact fonts on covers.
`creator/brand-profile.md` (anchor font, core colours, variable zone, never-us), the last 4 posts in
`creator/content-log.md`, and `creator/libraries.md` § Font pairings, § Caption styles, § Colour grades.

## Process
1. **Match mood to look.** Derive the video's mood in 3 words from the script, then choose:
   - **Font pairing** (FP-ID), not used in the last 4 posts, consistent with the mood
   - **Caption style** (C-ID), not used in the last 3 posts
   - **Grade** (G-ID), not used in the last 4 posts, and suitable for the footage's light
   - **Accent colour** for this post, which complements (doesn't replace) the core palette
2. **Spec sheet:**
   ```
   Headline: Fraunces SemiBold, 64–80pt equivalent, tracking −2%, sentence case
   Captions: IBM Plex Sans Medium, 42pt, white, 6% black shadow, max 2 lines, keyword in accent #F2A541
   Anchor:   [brand font] on the title card + end card
   Animation: words slide up 6px + fade, 4-frame stagger; keyword scales 100→108%
   Placement: centre-upper third; stay within the safe zone
   Grade:    G01 warm film: temp +8, tint +3, contrast −5, highlights −20, shadows +10,
             fade/lift blacks +8, sat −10, orange hue −5, grain 15, slight halation
   Palette:  core #… #… + accent #…
   ```
3. **App instructions:** exact steps in their app. If a Google Font isn't built in, tell them how to
   import it (CapCut desktop: system fonts; mobile: Text → Font → Upload or use the closest built-in, and name it).
4. **Readability check:** contrast ratio ≥ 4.5:1 against the footage (add a soft shadow or box if not),
   ≤ 7 words per caption screen, nothing under the UI.
5. **Thumbnail / cover:** cover text (≤ 4 words) in the headline font, with a face or object as the hero, and
   a 3×3 grid preview check against the last 8 covers so the profile grid looks varied but cohesive.

## Typography rules
- At most 2 typefaces per video plus the anchor.
- Use weight and size for hierarchy rather than more fonts.
- Avoid stacking drop shadows, strokes and glows together.
- If the creator's never-us list bans a font, it's banned, even if it's trendy.
