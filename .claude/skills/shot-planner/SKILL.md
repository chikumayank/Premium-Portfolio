# Shot Planner

## Inputs
Script (or idea), gear and constraints from `creator/brand-profile.md`, recent camera styles from
`creator/content-log.md`, and `creator/libraries.md` § Camera styles, § Transitions.

## Process
1. Choose a **primary camera style** (CS-ID) not used in the last 3 posts, plus a contrasting secondary style
   for b-roll. Explain the choice in one line.
2. Build the shot list:

| # | Script beat | Shot type (ECU/CU/MS/WS) | Angle | Movement | Lens/zoom | Duration to film | In-camera transition | Notes |
|---|---|---|---|---|---|---|---|---|

   - Get each important beat from **at least 2 angles**.
   - Plan **transitions in camera** (whip pan, hand-cover, match pose) by noting the out-shot and in-shot.
   - Add a **b-roll bank**: 8–15 detail shots (hands, textures, environment, reactions, food, feet walking,
     signs, sky), each 3–5s long.
3. **Light:** window position, time of day (golden hour windows for the location), backup plan
   (cheap LED, white wall bounce).
4. **Audio:** mic placement, room tone (record 10s), wild lines to re-record, natural-sound moments to capture.
5. **Shoot order:** group by location and light, not by script order. Give a timed schedule.
6. **Settings:** for phones, use 4K, 24/25fps for cinematic and 30fps for talking, 60fps for slow-mo shots, lock
   exposure and focus, clean the lens, use the 0.5x lens carefully (distortion near faces). For cameras: shutter ≈ 2× fps, ISO plan, and
   log/flat profile only if they will grade.
7. **Checklist:** batteries, storage, mic, tripod, reflector, props, outfit change (if posting multiple videos).

## Batching
If the user is filming several videos in one session, interleave them so outfits and locations are reused
efficiently, but make sure each video gets a **different** primary camera style.
