# Creator Edit Styles (TRENDS: "how do creators do X")

These are **style archetypes**: describe the techniques, then adapt them to the creator's brand. Don't clone any one creator's look.
Use 1 primary archetype per video and rotate across the week. Each style lists its signature techniques and effect IDs.

## How to use this in an answer
1. Ask (or infer) which style the user admires, or recommend 2–3 that fit the topic and the creator's skill level.
2. Give the **adaptation**: keep the technique, use the creator's own fonts, palette, signature and voice.
3. List the 3–5 specific moves with timestamps for their video and the how-to from `editing-playbook.md` and `effects-library.md`.
4. Log the style ID (ES##) in the content log's Notes, and avoid the same primary style twice in a row.

## Beginner progression (for creators new to editing)
Week 1–2: ES04, ES07, ES08 (one or two new skills each) → Week 3–4: ES03, ES14, ES16 → Month 2: ES02, ES05, ES18 →
Month 3+: ES01, ES09, ES11, ES17.
