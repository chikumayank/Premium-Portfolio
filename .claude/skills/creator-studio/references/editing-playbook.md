# Editing Playbook (EDIT)

## The 7-pass edit (the same order every time; it keeps beginners fast)
| Pass | What | Target time (60s reel) |
|---|---|---|
| 1. **Assembly** | Drop in the best takes in script order | 10 min |
| 2. **Tighten** | Cut every pause, breath, "umm" and repeated line. Start each clip on a word, not before it | 10 min |
| 3. **Coverage** | Add b-roll, screenshots and graphics over every noun or number; punch-ins to hide jump cuts | 15 min |
| 4. **Text** | Auto-captions → fix spelling (Hinglish needs manual fixes) → style; keyword text overlays | 10 min |
| 5. **Effects** | Only the recipe's 2–3 effect families, at the timestamps in the cut list | 10 min |
| 6. **Sound** | Voice cleanup, music at 10–20% under speech, SFX accents, one silence moment | 10 min |
| 7. **Look & export** | Grade, safe-zone check, cover frame, export | 5 min |
Watch the full video once **on mute** (does the text tell the story?) and once with **eyes closed** (does the audio tell the story?).

## Pacing maps (choose by recipe pace ID)
| Pace | Avg shot | Feel | Use for |
|---|---|---|---|
| P01 Hyper | 0.3–0.7s | Meme, montage | Openers, montages (never the whole video) |
| P02 Punchy | 0.8–1.5s | Energetic talking head | Tips, lists |
| P03 Beat-synced | 2–4 beats | Musical | Photo-dumps, travel |
| P04 Breathing | 2–4s | Cinematic, calm | Emotional, premium explainers |
| P05 Long take | 1 cut or none | Raw, trustworthy | "Yap" selfie, confessions |
| P06 Contrast | Slow build → hyper | Drama | News reveals, transformations |
Draw it like this: `0–3s HOOK fast | 3–15s steady | 15–20s breathe | 20–35s build | 35–40s DROP | 40–45s close`.

## Talking-head rules
- Jump cuts are fine. Hide every 2nd–3rd one with a punch-in (E-ZOOM-01) or b-roll.
- Alternate framings: wide (100%) → tight (120%) → b-roll → wide. Never 3 identical framings in a row.
- Eyes on the lens. Cut away when the speaker looks at notes.
- Add a pattern interrupt every 3–5 seconds: angle, text, b-roll, sound or graphic.

## B-roll rules
- Literal first (say "passport", show the passport), then emotional (a worried face, the clock).
- Hold each b-roll shot 1–2s (fast) or 2–4s (calm). Use speed 0.8–0.9x on handheld b-roll to smooth it.
- Free sources: your own phone library first, then screen recordings, then Canva or Pexels stock (avoid generic money piles).

## Instagram Edits: how-to essentials (versions change; look for the nearest equivalent)
- **New project:** pick clips → it builds a timeline. You can trim clips before they reach the timeline in newer versions.
- **Split / trim:** select clip → split at playhead; drag the edges.
- **Captions:** Captions → auto-generate → choose a language → edit words → choose a preset or style (newer versions include multiple caption presets, and bilingual captions in some regions).
- **Text:** Text → add → font, colour, background box, animation in/out → drag on the timeline.
- **Overlay/layers:** add media as an overlay (PNG tags, screenshots, Canva charts). Stack multiple layers.
- **Green screen / cutout:** green screen for a background behind you; cutout to isolate the subject (for text-behind-subject, duplicate the clip, cut out the top copy, and put text between them).
- **Keyframes:** select clip → keyframe → set scale or position at two points (punch-ins, slow push, Ken Burns).
- **Speed:** select clip → speed. For ramps, split into 3 and set slow → fast → slow.
- **Effects:** the Effects panel (Fisheye, Bounce, Blackout, glitch, film, and more, depending on version).
- **Audio:** voice enhance or noise reduction; music library; sound effects (searchable); voiceover recording; volume per clip.
- **Templates and ideas:** use the inspiration or ideas tabs to study structures, not to copy them.
- **Export:** highest quality, no watermark; share to Instagram directly or save to the gallery (for YouTube Shorts).
**If Edits can't do something** (motion tracking, counters, advanced speed curves, morph cuts), use CapCut for that one shot, export it, and bring it back into Edits.

## CapCut fallback map
Keyframes (diamond icon) · Speed → Curve · Text → Animation / Tracking · Overlay → Remove BG / Chroma key · Effects → Video effects · Audio → Enhance voice · Auto captions → edit style.

## Export settings
- 1080×1920, 9:16, 30fps (or 24/25 if shot so), highest bitrate.
- Loudness about −14 LUFS; voice peaks at −6 to −3 dB, never clipping.
- **Safe zone:** keep text out of the bottom ~20% and right ~15%, and keep the top 10% clear of key info.
- Choose the cover frame or upload a cover (1080×1920 with the important part in the centre 1080×1440 so the 4:5 grid crop works).
- YouTube long-form: upload in 4K even if shot in 1080p, for better compression.

## Fixing common problems
| Problem | Fix |
|---|---|
| Feels slow | Cut 10–20% more; start every clip on the first word; remove the intro sentence |
| Feels chaotic | Fewer effects; return to one pace; let 1 shot breathe before the payoff |
| Looks amateur | Fix audio first, then light, then text consistency, then grade |
| Viewers drop at 3s | The hook isn't paid off visually. Show the payoff in frame 1 |
| Drop in the middle | Add a re-hook at 40% and a pattern interrupt every 3–5s |
| Same as last video | Run the recipe roll; change the pace, caption style and camera style first |
