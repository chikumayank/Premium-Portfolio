# Creative Libraries

Shared menus that every skill picks from. Each item has an ID (e.g. `F07`) for the content log.
Add your own items at the end of any list. A bigger library gives more variety.

|---|---|---|

| T04 | Object wipe / hand cover | Hand or object covers lens |
| T05 | J-cut / L-cut | Audio leads or trails the picture |
| T06 | Speed ramp | Slow → fast → slow on movement |
| T07 | Zoom punch-in / jump zoom | 110–130% scale on beat |
| T08 | Mask reveal | Through a door, person or pole |
| T09 | Light leak / flash frame | 2–4 frame white or colour |
| T10 | Spin / rotate | 90–180° rotation on beat |
| T11 | Glitch / RGB split | Tech, comedy |
| T12 | Morph cut / smooth jump | Hide jump cuts |
| T13 | Sound-bridge cut | A sound carries across the cut |
